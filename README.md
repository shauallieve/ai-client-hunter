# AI Client Hunter — Telegram Edition

Поиск новых запросов на разработку **только из Telegram**. Подходит для фрилансера, который делает сайты, веб-приложения, Telegram-ботов, CRM и автоматизации.

- Бот получает **новые** сообщения из подключённых групп и каналов или пересланные владельцем объявления.
- Сообщения с явным запросом на разработку сохраняются в SQLite-backed Durable Object Cloudflare (без отдельного D1).
- Для каждого лида: источник, текст заявки, рейтинг совпадения, публичный **@username** автора/контакта (если Telegram его предоставляет), ссылка на исходное **публичное** сообщение.
- Лиды защищены `DASHBOARD_TOKEN`, который не должен попадать в GitHub.
- Кнопка «Написать в Telegram» открывает публичный контакт. Отклики отправляются только вручную.
- Лиды старше 30 дней удаляются при чтении списка. Нерелевантные сообщения не сохраняются.
- **Не умеет искать по всему Telegram** или узнавать скрытые контакты.

## Telegram setup

### 1. Создай своего бота

Открой Telegram → [@BotFather](https://t.me/BotFather) → `/newbot`. Запомни выданный токен, **никому не отправляй его** и не коммить в репозиторий.

### 2. Cloudflare Worker Secrets

В Cloudflare → **Workers & Pages → ai-client-hunter → Settings → Variables and Secrets** добавь четыре значения (как **Secret**, не обычные публичные переменные):

| Название | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен из @BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | Случайная строка 20–60 символов, буквы/цифры/`_`/`-` |
| `DASHBOARD_TOKEN` | Другая случайная строка минимум 20 символов — пароль личной панели |
| `TELEGRAM_OWNER_ID` | (Позже) твой цифровой Telegram ID; нужен для пересылки заявок боту в личку |

Для генерации двух отдельных секретов на своём компьютере:
```bash
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```
Выполни дважды. **Не используй одинаковую строку** для двух секретов.

Дополнительный фильтр (необязательный): `TELEGRAM_ALLOWED_CHATS` = список chat ID через запятую; если задан, бот сохраняет групповые сообщения только от этих чатов.

### 3. Публикация

Репозиторий подключён к **Cloudflare Workers Builds**, не Cloudflare Pages.

- Repository: `shauallieve/ai-client-hunter`
- Branch: `main`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Root directory: корень репозитория

В `wrangler.jsonc` уже указана Durable Object `LeadStore` с SQLite. Отдельную базу создавать не нужно.

После успешного деплоя открой:
`https://ai-client-hunter.kazatu2004-9ed.workers.dev/api/health`.

Нужно увидеть `mode: "telegram-only"`, `store: true`. Если `dashboard: false` или `bot: false`, секреты ещё не заданы.

### 4. Включи webhook

Открой сайт AI Client Hunter, введи свой `DASHBOARD_TOKEN`, перейди в **Настройки → Активировать Telegram webhook**.

Это автоматически вызовет Telegram `setWebhook` для адреса `/api/telegram/webhook` и установит защитный `secret_token`.

**Никогда не вставляй токен BotFather в URL сайта или публичный чат.**

### 5. Начни получать лиды

**Способ А — автоматическое отслеживание группы.** Добавь бота в группы по разработке, в которые тебе разрешено его приглашать. Чтобы он читал обычные сообщения, сделай его администратором группы **или** отключи Privacy Mode у @BotFather через `/setprivacy`, затем удали и добавь бота заново. Для каналов бот должен быть добавлен администратором. Он видит только **новые** сообщения после подключения, не старую историю. Соблюдай правила чатов и приватность участников.

**Способ Б — вручную пересылать заявки.** Открой своего бота в Telegram и напиши `/start`. Он ответит твоим цифровым Telegram ID. Добавь это число в Cloudflare как Secret `TELEGRAM_OWNER_ID`, затем пересылай боту сообщения о заказах из групп, которые ты читаешь. Если при пересылке Telegram скрывает автора или ссылку, контакт автоматически не появится.

После поступления заявки открой **Лиды** на сайте и нажми **«Написать в Telegram»** (если у автора есть публичный контакт), либо **«Исходное сообщение»**, чтобы ответить в чате.

## Ограничения и этика

- Bot API не ищет глобально по всем группам и не предоставляет историю чатов задним числом. Бот видит сообщения только в доступных ему чатах. [Официальная документация Telegram](https://core.telegram.org/bots/faq).
- Скрипт не определяет телефонные номера, скрытые username или закрытые профили, не обходит ограничения Telegram.
- **Автор может не указывать публичный username** — тогда прямой контакт отсутствует, но ссылка на публичный пост может оставаться.
- Рейтинг работает по словам (без стороннего AI API). Потребности и актуальность заказа нужно проверять.
- Нет автоматических личных сообщений, спама или массового рассылания откликов.
- `DASHBOARD_TOKEN` хранится в `sessionStorage` браузера до закрытия вкладки; настройки откликов и статусы — локально в `localStorage`.

## Разработка

Node.js 20+:
```bash
npm install
npm run build
npm test
npx wrangler dev
```

Локальный Worker с Durable Object стартует через `wrangler dev`. Для удалённого деплоя: `npx wrangler deploy`.

Проверка: `GET /api/health` без авторизации; `GET /api/leads` требует `Authorization: Bearer <DASHBOARD_TOKEN>`.

**Важно:** исходники в GitHub и настройка Worker могут быть развернуты, но сам Telegram-бот не начнёт собирать лиды до создания токена, настройки секретов и webhook.
